# 玄鉴志 · 望月李氏资料库

一个关于《玄鉴仙族》的静态资料站。收录三玄诸道、道统谱系、势力门派、人物志、修炼体系、器物志、名词词典、李氏宗谱、大事记与典籍库。整体为青绿山水/水墨风格，支持深色与浅色两套主题。

## 在线版

https://nins971197.github.io/xuanjian-site/

## 直接打开

双击 `index.html` 即可（数据全部内嵌在 `assets/js/data.js`，无需服务器）。

如果浏览器对本地文件限制较多，也可以在 PowerShell 中运行：

```powershell
.\serve.ps1
```

然后访问 `http://127.0.0.1:8765/`。

## 目录

```
index.html
assets/
  css/style.css
  js/data.js      # 单文件构建与完整离线数据（535 篇典籍、409 人物、92 势力、109 名词、232 器物、71 族谱节点）
  js/data-core.js # 在线站点首屏数据（不含典籍全文）
  js/data-docs.js # 按需加载的 535 篇典籍
  js/app.js       # 路由、渲染、搜索、族谱、抽屉
serve.ps1
```

## 新增内容

- **图像信息提取与复核**：参考长表经实体归一后，收录 56 条道统结构、32 支三玄谱系、30 个势力关系和 11 个纪年节点，直接并入原栏目与主大事记；不另设独立总表页。
- **别名校正**：“青池门”“青池魔门”“青迟魔门”均统一为青池宗的异名；不再拆成多个互相冲突的势力。
- **道统谱系**：五德 → 五水 → 府水逐层点开，显示仙基、神通与功能特性；另含十二炁、阴阳、三雷（元磁）、独立虹霞与并古。十二炁补入下仪；并古补齐司天、身夔，并列出长庚剑道，三巫与并古诸家分层呈现。
- **器物志**：232 件兵器、甲衣、印信、符令、丹药、图卷与灵材，按品阶/类别筛选，附原文摘录。
- **势力沿革**：22 个重点势力的来龙去脉，在势力卡片抽屉中查看。
- **人物事件**：409 位人物；人物抽屉以“原文传记·完整句节选 + 事件索引 + 原文事件”呈现。2026-11-01 重做了非核心人物的阵营归并：先采用人工覆盖，再按姓氏兜底，不再根据正文里出现“朝廷”“摩诃”等词强行判派；71 个宗谱节点均归入望月湖李家，并保留释门、宋廷等兼属信息。
- **三玄位阶/发展**：玄主 → 四弟子 → 门下 → 人间 → 修士；三玄对照、青玄/兜玄/通玄/游离四组谱系，以及 14 个三玄史事件。
- **典籍库**：按总览/人物志/势力志/神通志/法器/考据分组，显示完整提要+要点+折叠章节目录，不再直接展示语料库的截断摘要。
- **青绿山水主题**：深色为墨绿山水，浅色为米纸水墨；2026-11-01 将主页改为宽幅远山、云海与小舟构图，移除了压住主峰的旧剪影和圆镜，强化桌面与手机端的留白层次。
- **互动水墨**：主页按 `art_of_ink` 原作移植了 PixelFlow 的 WebGL 流体模拟。左键拖动注入速度，右键拖动加热，`P` 暂停、`R` 重置、`-` / `+` 调整流体采样精度；参数与更新顺序对齐原作，静态山水仍然是无 WebGL 或减少动态效果时的回退。
- **大事记**：扩到 60 个节点，新增「上古」阶段，补入梁治子、人皇共顼、雷宫、真火被折、平明津天变、闰余有缺、王朝链等远古事件。

## 说明

- 这是同人向资料整理，非官方设定集；章节号以你提供的文本为准。
- 人物志中的“原文传记”按底本回查后取完整句；典籍库中的“资料提要”可能来自二次整理，不再冒充小说原文，遇到续章补记会明确标出校订范围。
- 剧透预警：默认展示到第 1580 章，包含明阳四义、李绛迁投释、燕都之战等终局内容。
